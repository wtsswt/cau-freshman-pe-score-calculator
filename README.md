# 中国农业大学 · 身体运动功能课程成绩计算器

2026—2027 学年度秋季学期「身体运动功能」课程成绩计算器，纯前端单文件网页，无需安装、无需联网。

**在线使用：** https://wtsswt.github.io/cau-freshman-pe-score-calculator/

## 功能

- 按课程考核评分标准计算五个分项：课程思政 15 + 理论考试 10 + 身体综合测试 30 + 专项素质 30 + 课外体育活动 15
- 男女分开评分（引体向上／仰卧起坐、1000／800 米、第三项考核内容自动切换）
- 体测部分按《国家学生体质健康标准》（2014 年修订）大一大二组评分，含附加分
- 支持选择「满分／优秀／良好／及格」参考档位，一键填入对应成绩
- 输入内容自动保存在本机浏览器，下次打开自动恢复
- 五个分项可分别重置

## 评分依据

- 《2026—2027 学年度秋季学期身体功能课考核评分标准》
- 《国家学生体质健康标准》（2014 年修订）
